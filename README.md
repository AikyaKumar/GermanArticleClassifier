# GermanArticleClassifier
A simple Python script that classifies German nouns into their correct definite articles: der, die, or das, using hardcoded examples.

# 🧠 How It Works

The script contains predefined lists of nouns for each German article:

- **der** – masculine nouns  
- **die** – feminine nouns  
- **das** – neuter nouns  

When a noun is input, the script checks which list it belongs to and returns the corresponding article. If the noun is not found, it returns `"Unknown"`.

# 📦 Requirements

No external libraries are required. Just Python 3.
